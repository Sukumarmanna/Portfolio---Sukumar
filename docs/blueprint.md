# **App Name**: Cyberfolio

## Core Features:

- Hero Section Terminal Intro: Displays a minimalist terminal-style greeting that smoothly transitions into a professional headline to grab visitor's attention immediately.
- Interactive Experience Timeline: A dynamic, interactive timeline to showcase professional experience progression, with hover effects that reveal technical achievements and experience.
- Project Bento Grid: Showcases key projects in a visually appealing, modern grid layout that is easy to navigate, with clear descriptions of my main projects.
- PhishGuard Project Case Study: Presents a case study for PhishGuard, detailing the problem, solution, tech stack, and results, focusing on its real-time URL classification capabilities. Highlights the integration between Next.js frontend and a Python/ML backend as a tool for users.
- SysAudit Project Card: Create card highlighting key feature.
- Live Data Skills Animation: Animated display of skills using Framer Motion, providing dynamic stats for skills in React, Next.js, and data visualization. Visual representation of the user's skill set in a engaging way.

## Style Guidelines:

- Primary color: Electric Emerald (#50C878) for a modern, energetic, and secure feel, representing growth and innovation in tech.
- Background color: Deep Charcoal (#121212) to provide a dark, cyber-minimalist aesthetic.
- Accent color: Slate Grey (#708090) used for text and minor UI elements, offering a neutral contrast that ensures readability without detracting from the primary and secondary colors.
- Body and headline font: 'Inter', a grotesque-style sans-serif providing a modern, machined, neutral aesthetic suitable for both headlines and body text.
- Use clean, line-based icons to maintain a minimalist aesthetic.
- Implement a glassmorphic navbar and a subtle moving 'grid-mesh' background to symbolize network security, maintaining a cutting-edge but subtle appearance.
- Subtle animations and transitions using Framer Motion to create a dynamic and engaging user experience without being distracting.
